# pop-Eyes — подбор подрядчиков для мероприятий

Заказчик задаёт город, дату, формат, категорию, бюджет и, при желании, язык, длительность и пожелания. Цель MVP — показать до трёх подходящих подрядчиков с объяснениями выбора. Правила допуска и ожидаемый сценарий описаны в [плане хакатона](docs/HACKATHON_PLAN.md).

## Что готово сейчас

Есть [одностраничный интерфейс](frontend/index.html) с формой и демонстрационными ответами для подбора, отсутствующей категории, отсутствия подходящих подрядчиков и резервного режима. **Это примеры отображения, не настоящие рекомендации.** Интерфейс пока не обращается к API и не использует данные каталога.

Для просмотра откройте `frontend/index.html` в браузере. Выберите «Пример ответа», заполните обязательные поля и нажмите «Показать пример результата». Сервер и зависимости для этого не нужны.

## Контракт для подключения API

Планируемые маршруты: `GET /api/options` для значений формы и `POST /api/recommendations` для подбора. Форма готовит запрос с полями `city`, `date`, `event_type`, `category`, `budget_kzt`, `duration_hours`, `language`, `preferences`. Необязательные язык и длительность передаются как `null`.

Интерфейс ожидает `status` (`matched`, `category_absent`, `no_matches`), `message`, `cards`, `eligible_count`, `selection_mode` (`ai` или `fallback`). Для карточки используются `id`, `name`, `categories`, `city`, `price_from_kzt`, `reason`. Точные имена полей карточки и справочника `/api/options` необходимо согласовать с участником backend перед подключением.
